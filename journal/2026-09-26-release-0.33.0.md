# Release Arclith 0.33.0

## Contexte

Le framework vient de quitter l'organisation Rekipe pour devenir un projet
autonome de Karned Agency. La première publication depuis le nouveau dépôt doit
à la fois livrer le toolkit agent ajouté après 0.32.0 et prouver que les deux
chaînes PyPI OIDC restent fonctionnelles après le transfert.

## Décision

- publier `arclith==0.33.0` afin de refléter l'ajout du toolkit agent public ;
- publier `arclith-cli==0.30.0` avec une dépendance minimale
  `arclith>=0.33.0` ;
- conserver les deux noms de packages PyPI et les environnements GitHub
  `pypi` / `pypi-cli` ;
- produire un tag Git signé `v0.33.0` après merge de la PR de release ;
- vérifier GitHub Release, PyPI JSON, Simple API et installation consommateur
  sans cache avant de considérer le déménagement terminé.

## Compatibilité

Les contrats runtime, formats de recettes, manifests et six blueprints restent
compatibles. Le changement visible concerne l'identité publique, les URLs
générées et la version minimale utilisée par les nouveaux projets CLI.

## Validation attendue

- `make quality` et `make docs` ;
- suite CLI complète gelée ;
- construction des quatre distributions et contrôle de leurs métadonnées ;
- CI du SHA exact et audit des conversations de review ;
- publication OIDC des deux projets PyPI ;
- installation `arclith==0.33.0` et `arclith-cli==0.30.0` depuis PyPI sans
  cache, puis smoke du CLI et d'un projet généré.
